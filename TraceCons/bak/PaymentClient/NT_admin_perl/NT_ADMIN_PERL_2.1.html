Perl Integration Examples

This is an example of Perl integration to the Payment Client for the Administration Methods Payment Capture and Shopping Transaction History Search.

Before you start

Step 1. The following assumptions are made:

    • You have Perl installed on your server
    • Your Web Server is configured to use Perl/CGI
    • You have a Java Runtime Environment installed on your server
    • You have Administrator privileges for your computer
    • The Payment Client has been installed
    • Your merchant record at the Bank has the following configuration:
      • Merchant granted privilege 'advanceMA';
      • Merchant Agent granted privilege 'advanceMA'; and
      • Merchant Transaction Type is Auth/Capture.

Step 2. You will need the following information prior to the install:

    • Payment Client installation directory
    • Web Server cgi-bin directory (eg. c:\Inetpub\cgi-bin)
    • Directory of your Perl executable (eg. c:\perl\bin)
    • Perl scripts directory
    • HTML file directory (eg. c:\Inetpub\wwwroot)

Installing Perl integration examples

Step 3. Running the Installshield
    • Execute the file .\NT_admin_perl\setup.exe
    • At the prompts enter the information you have gathered at Step 2

Running the Perl Interface

Step 4. Running the PCThread listener

    • To start using the Perl interface the PCService class must be run. This initiates a listener thread for the Perl to address. This listener thread is initiated by typing "java PaymentClient.PCService" at the command prompt.

Step 5. Running the Perl example
    • Once the installation of the Perl Payment Client Interface is complete and the listener thread is running, you should be able to run the examples that use the Perl Interface and were included in this package.
      Admin Capture: http://localhost/AdminCapture.html
      Admin Shopping Transaction Search: http://localhost/AdminShopTrans.html

How to use the examples in your Shop & Buy

Before integrating into your Shop & Buy it is important to understand the message flow of the files contained within the package.

Admin Capture:
Once the AdminCapture.html file's form is completed, the following steps occur:

    • The form submits the field values to AdminCapture.cgi
    • This cgi will make calls to the PaymentClient.pl which marshalls the calls across a socket to the Java components of the Payment Client. This is the reason for the other Perl scripts to maintain this socket connection.
    • The Java component of the Payment Client takes care of encryption and messaging to the Payment Server.

NOTE : For the integrator much of this logic is hidden. The CGI scripts are well documented to show the basic method of initializing a payment.

Logical flow through an SSL Payment process:

    • Creating a Payment Client instance
    • Sending a doAdminCapture call
    • Taking an encrypted DR (Digital Receipt)
    • Closing the instance

 

Admin Shopping Transaction Search:
Once the AdminShopTrans.html file's form is completed, the following steps occur:

    • The form submits the field values to AdminShopTrans.cgi
    • This cgi will make calls to the PaymentClient.pl which marshalls the calls across a socket to the Java components of the Payment Client. This is the reason for the other Perl scripts to maintain this socket connection.
    • The Java component of the Payment Client takes care of encryption and messaging to the Payment Server.

NOTE : For the integrator much of this logic is hidden. The CGI scripts are well documented to show the basic method of initializing a payment.

Logical flow through a Admin Shopping Transaction Search process:

    • Creating a Payment Client instance
    • Sending a doAdminShoppingTransactionHistory call
    • Taking an encrypted DR (Digital Receipt)
    • Closing the instance

For further information refer to the in-code documentation and the Payment Client Manual.
