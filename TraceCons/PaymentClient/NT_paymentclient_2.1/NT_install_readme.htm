NT Payment Client Installation

This is the procedure to install an NT Payment Client.

Before you start

Step 1. The following assumptions are made:

    • You have a Java Runtime Environment installed on your server
    • You have Administrator privileges.
    • You have received the "qsi.3" and "qsi.4" key files from your Payment Service Provider. (Look for them in the installation directory).
    • You have a valid Merchant Id

Step 2. You will need the following information prior to the install:

    • Determine where you would prefer the Payment Client to be installed. The default destination is C:\QSIPayments
    • The URL of the Payment Server the Payment Client will talk to. If you are unsure of this URL, consult your Payment Service Provider.
    • Determine if you require the Payment Client to be installed with COM support. If COM installation is selected, the installation will register the COM object and install tools for the object's unregistration and reregistration.

Installing the Payment Client

Step 3. Running the InstallShield

    • Using NT Explorer, execute the file NT_paymentclient_2.1\setup.exe
    • Follow the prompts and enter the information from step 2 when required.
    • You may be prompted to restart your computer. Please do so.

Step 4. The post-installation test

        • You may test your installation upon completion by running Start | QSIPayments | PaymentClient | Test Payment Client.
        • The self-test is in two parts. The first test determines whether the Payment Client object can be instantiated. The second test determines whether the system can formulate a Digital Order.
