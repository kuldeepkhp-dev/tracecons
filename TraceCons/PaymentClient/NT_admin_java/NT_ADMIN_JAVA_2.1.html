Java Integration Examples

This is an example of Java integration to the Payment Client for the Administration Methods Payment Capture and Shopping Transaction History Search.

Before you start

Step 1. The following assumptions are made:

    • You have Java installed on your server
    • Your Web Server is configured to use Java servlets, and the servlet engine's classpath points to both the Payment Client classes directory (eg C:\QSIPayments\PaymentClient\classes) and the Web Server's servlet directory. (eg C:\Inetpub\servlet)
    • You have Administrator privileges for your computer
    • The Payment Client has been installed
    • Your merchant record at the Bank has the following configuration:
      • Merchant granted privilege 'extPaySelect';

Step 2. You will need the following information prior to the install:

    • Web Server servlet directory (eg. c:\Inetpub\servlet)
    • HTML file directory (c:\Inetpub\wwwroot)

Installing Java integration examples

Step 3. Running the Installshield
    • Execute the file .\NT_admin_java\setup.exe
    • At the prompts enter the information you have gathered at Step 2

Step 4. Running the Java servlet example
    • Once the installation of the Java Payment Client Interface is complete and the web server is configured to execute Java servlets, you should be able to run the example that uses the Java Interface. This should be able to start from the following URLs: http://localhost/Java_AdminCapture.html & http://localhost/Java_AdminShopTrans.html.

How to use the examples in your Shop & Buy

Before integrating into your Shop & Buy it is important to understand the message flow of the files contained within the package. Once the Java_Admin*.html file's form is completed, the following steps occur:

    • The form submits the field values to AdminCapture_Servlet.class and AdminShopTrans_Serlvet.class respectively.
    • These servlets make calls to the Payment Client, which takes care of encryption and messaging to the Payment Server.

NOTE : For the integrator much of this logic is hidden. The servlet source is well documented to show the basic method of initializing a message.

Logical flow through an Administration Method process:

    • Creating a Payment Client instance
    • Sending a doAdminCapture or doAdminShoppingTransactionHistory call
    • Taking and encrypted DR (Digital Receipt)
    • Closing the instance

For further information refer to the in-code documentation and the Payment Client Manual.
